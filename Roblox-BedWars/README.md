## Usage

1. Open executor: **Fluxus**, **Delta**, **Wave**, **Synapse X**
2. Join **Bed Wars** (Game ID: 6872265039)
3. Paste `BedWars_Ultimate.lua` and execute
4. Press **Right Alt** to toggle UI
