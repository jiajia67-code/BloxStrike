## 📋 FAQ

### General

**Q: What is BloxStrike?**
A: BloxStrike is a modular FPS cheat script for Roblox, inspired by CS2.

**Q: Is it free?**
A: Yes, BloxStrike is completely free and open source.

**Q: Which game does it work on?**
A: BloxStrike works ONLY on BloxStrike game (PlaceId: 114234929420007).

### Installation

**Q: How do I install BloxStrike?**
A: See the [Installation Guide](README.md#-installation) in README.

**Q: Which executor should I use?**
A: We recommend Fluxus, Delta, Wave, or Potassium. See [Supported Executors](README.md#-supported-executors).

**Q: Do I need to download all files?**
A: Yes, you need the `modules/` folder and `BloxStrike.lua`.

### Usage

**Q: How do I open the menu?**
A: Press INSERT key in-game.

**Q: Features aren't working**
A: Make sure you're in the BloxStrike game and using a supported executor.

**Q: I'm getting errors**
A: Try using `BloxStrike_Fixer.lua` to auto-fix issues.

### Technical

**Q: Can I use this on mobile?**
A: Yes, BloxStrike supports mobile with touch controls.

**Q: Is it safe?**
A: No cheat is 100% safe. Use alternate accounts.

**Q: Can I contribute?**
A: Yes! See [CONTRIBUTING.md](CONTRIBUTING.md).
